InstantTranslate 0.7.2 快速开始
=============================

1. 解压整个 ZIP，不要只单独拖出 EXE。
2. 双击 InstantTranslate.exe。
3. 首次启动会打开英文设置：填写 DeepSeek API Key，点击“Test connection”，成功后保存；右上角“中文”可切换界面。
4. 在记事本、网页或文档中用鼠标拖选文字，译文会显示在选区附近。

微信无法自动取词时：

1. 在微信里选中文字并由你自己按 Ctrl+C。
2. 按 Ctrl+Shift+T；也可右键托盘图标，选择“翻译剪贴板”。

常用操作：

- 托盘图标：设置、启用/暂停、翻译剪贴板、修复划词捕获、关于、退出。
- 浮窗图钉：保留窗口；保留后可拖动，译文显示后任意窗口均可从边缘调整尺寸。
- 正文：主动点击后可像普通文本一样拖选和右键复制；长文会在窗口内滚动。
- 浮窗 ×：关闭当前窗口。
- 浮窗铅笔：编辑译文；Ctrl+Enter 主动保存修正，Esc 取消。保存的修正会为当前 Windows 账户加密，可在设置中清空。
- 语言按钮：在中文与英文目标之间互换。
- Explain / 解释：在译文完成后解释本次原文；在译文正文中选中一段后，也可以单独解释该段。解释会以中文显示在原窗口内容区，可复制、重试或返回译文；Esc 也会返回。
- 设置右上角“中文 / English”：切换整个程序的界面语言；保存后应用到浮窗和托盘。
- 设置中的 English / Chinese translation font：分别控制英文与中文译文字体。
- 设置中的 Popup style / 浮窗样式：可在默认的 Minimal / 极简、Bubble / 气泡、Bubble 2.0，以及新的 Bubble 3.0 · Glass / 液态玻璃和 Bubble 3.0 · Color Glass / 彩色玻璃之间切换。原气泡 2.0 的粉蓝紫渐变保持不变；两款 3.0 能透出后方应用画面，文字不跟随整体变淡。
- Use surrounding context：默认关闭；开启后会把选区所在段落作为翻译参考发送给服务。
- Translation mode / Writing style：在速度、精度和表达风格之间选择。
- Personal glossary：每行填写“原词 => 指定译法”，只会发送当前选区命中的术语。
- 设置中的 Compatibility clipboard fallback 默认关闭；只有不提供无障碍文本的应用才建议主动开启，因为它会在自动取词时临时改变系统剪贴板。

说明：

- v0.7.2 新增透明玻璃样式，修复解释层与原译文的透叠，并同步问答窗切换样式后的圆角；不进行实时背景模糊或物理折射。复杂、很暗的背景可能影响文字对比度，可切回原有实色样式。
- v0.7.1 改进 Edge PDF 滚动、缩放后的选区读取与恢复；无需开启剪贴板兼容模式。
- Zotero 内置 PDF 阅读器兼容问题尚未解决，本次未修复其取词插件。
- 程序需要 Windows 10/11 x64，不需要另装 .NET。
- API Key 保存在 Windows 凭据管理器。
- 原文和译文默认不写入磁盘；内存缓存会在退出时清空。只有你主动保存的修正会进入加密翻译记忆。
- 解释请求会使用当前配置的 DeepSeek 服务，但解释内容、原文和译文不会保存到缓存、翻译记忆或性能诊断中。
- 托盘“Copy performance diagnostics / 复制性能诊断”只复制耗时与输入捕获状态，不包含原文、译文、API Key 或 Endpoint。
- 当前程序没有商业代码签名，Windows 首次运行可能提示“未知发布者”。
- 如需确认下载完整性，可对 ZIP 计算 SHA-256，并与同名 .sha256 文件比较。
